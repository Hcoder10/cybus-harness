# Cohesion

Covers whether the whole game reads as one thing made by one team: screens, HUD, world, characters, VFX,
motion, audio and copy.

## Capture
- One contact sheet sampling every screen, the HUD in play, world views, characters, key VFX moments, plus
  the style guide and the reference board.

## Anchors
- **1-2**: pieces from different games stitched together.
- **4**: a shared palette but mixed fonts, shapes and styles; free-model pieces clash with custom ones.
- **7**: one visual language: UI and world share palette, shapes and mood; VFX colours from the palette;
  icons in one family; copy in one voice.
- **9**: a unified identity: a stranger would recognise the game from any single frame; the UI's shape
  language echoes the world's; motion, sound and VFX share timing and personality.

## Checks
1. **Palette adherence.** Colours sampled across the captures belong to the style guide.
2. **Type adherence.** Only the chosen faces and the type scale.
3. **Shape language.** The same radii / angles / strokes in UI, icons, props and VFX shapes.
4. **Mood match.** Lighting mood, UI mood, music mood and copy tone agree.
5. **Motion match.** The same easing personality in UI, camera and animation.
6. **No leftovers.** No template, placeholder, debug or default elements anywhere.
7. **Naming and copy.** Button labels, item names and tutorials share one voice; consistent capitalisation.

## Common failures -> fixes
- UI looks like a different game from the world -> derive UI accents and textures from the world palette
  and materials.
- One screen built later in a different style -> rebuild it from the kit components.
